# AI Agent 岗位与面试计划

## 面试准备目标

不仅能解释概念，还要能够：

- 画出系统架构并说明组件职责。
- 比较不同实现方案的取舍。
- 讲清工具调用、状态更新和任务恢复的执行链路。
- 排查失败、延迟、成本和质量问题。
- 解释项目中的安全边界、测试策略和生产部署方式。
- 诚实说明项目中亲自实现的部分、取舍和不足。

## 面试题覆盖范围

### LLM 应用基础
- 直接调用模型 API 与使用 LangChain 有什么区别？
- Token 与上下文窗口是什么？
- 为什么结构化输出仍然需要校验？
- 如何处理流式响应、超时和模型输出异常？

### Tool Calling
- Tool Calling 的完整执行链路是什么？
- 模型是否直接执行工具？
- 如何定义工具 Schema 并验证参数？
- 工具失败时如何决定重试、返回错误或终止？

### RAG
- RAG 为什么需要切分文档？
- Embedding、召回、重排序各自解决什么问题？
- 如何评估检索质量和最终答案质量？
- 何时直接查询数据库更合适，何时需要 RAG？

### LangGraph 与 Memory
- State、Node、Edge 分别是什么？
- Workflow 和 Agent 有什么区别？
- 如何处理循环与终止条件？
- Checkpoint、短期记忆和长期记忆有什么区别？
- 如何实现人工审核后恢复执行？

### MCP 与 Multi-Agent
- MCP 解决什么问题？与 Tool Calling 有什么区别？
- MCP Server 和 Client 分别承担什么职责？
- 什么时候需要 Multi-Agent？
- Supervisor、Router 和独立 Agent 有什么取舍？
- 多 Agent 如何共享状态、处理失败和控制成本？

### 评测与生产工程
- 如何定义 Agent 的任务成功率？
- 如何建立可重复的评测集？
- 如何追踪一次 Agent 执行？
- 如何防范 Prompt Injection？
- 如何保证团队权限隔离？
- 如何处理幂等性、重复执行、超时和重试？
- 如何控制 Token 成本和延迟？

## 每节面试练习要求

每节 3–5 道题，至少覆盖：
1. 一道基础原理题。
2. 一道机制或代码执行题。
3. 一道比较/设计题。
4. 视主题增加一道故障排查或安全题。

参考答案需说明原理、适用场景、取舍和常见误区。重要问题可追加追问与项目化答案。
