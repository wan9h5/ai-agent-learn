# 第 8 周：MCP

## 本周目标
围绕“MCP”完成 3 节课，并将成果接入持续演进的项目。

## 课程安排

### S8-01：MCP 架构、Tool、Resource 与 Prompt

**实践任务：** 理解 MCP 的客户端、服务端和能力发现方式，并与普通工具调用比较。

**本节必须包含：** 术语中英对照、原理解释、可运行代码、执行链路、项目集成、测试、Summary 和 3–5 道面试题。

### S8-02：使用 Python MCP SDK 编写 MCP Server

**实践任务：** 暴露一个受控的只读查询工具，并提供启动和调试步骤。

**本节必须包含：** 术语中英对照、原理解释、可运行代码、执行链路、项目集成、测试、Summary 和 3–5 道面试题。

### S8-03：MCP Client 接入 Agent 与安全边界

**实践任务：** 让 Agent 使用 MCP 工具，验证身份、输入、权限和失败处理。

**本节必须包含：** 术语中英对照、原理解释、可运行代码、执行链路、项目集成、测试、Summary 和 3–5 道面试题。

## 本周验收
- 三节课的代码均能按文档运行。
- 至少完成一项异常场景测试。
- 更新项目 README 与学习进度。
- 能口头解释本周核心架构决策。
