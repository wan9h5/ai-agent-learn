# 第 5 周：RAG

## 本周目标
围绕“RAG”完成 3 节课，并将成果接入持续演进的项目。

## 课程安排

### S5-01：文档解析、切分与 Embedding

**实践任务：** 导入一组文档，切分文本并生成向量，记录来源元数据。

**本节必须包含：** 术语中英对照、原理解释、可运行代码、执行链路、项目集成、测试、Summary 和 3–5 道面试题。

### S5-02：向量检索、召回与重排序

**实践任务：** 构建检索接口，用固定问题集观察召回结果和排序差异。

**本节必须包含：** 术语中英对照、原理解释、可运行代码、执行链路、项目集成、测试、Summary 和 3–5 道面试题。

### S5-03：检索结果注入、来源引用与质量检查

**实践任务：** 让 Agent 基于检索内容回答，并在无相关证据时明确说明。

**本节必须包含：** 术语中英对照、原理解释、可运行代码、执行链路、项目集成、测试、Summary 和 3–5 道面试题。

## 本周验收
- 三节课的代码均能按文档运行。
- 至少完成一项异常场景测试。
- 更新项目 README 与学习进度。
- 能口头解释本周核心架构决策。
