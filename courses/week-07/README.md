# 第 7 周：Memory 与人工审核

## 本周目标
围绕“Memory 与人工审核”完成 3 节课，并将成果接入持续演进的项目。

## 课程安排

### S7-01：对话状态、短期记忆与长期记忆

**实践任务：** 比较对话历史、任务状态和长期记忆，避免将它们混为一谈。

**本节必须包含：** 术语中英对照、原理解释、可运行代码、执行链路、项目集成、测试、Summary 和 3–5 道面试题。

### S7-02：Checkpoint、持久化与恢复

**实践任务：** 保存执行状态，模拟服务中断后恢复任务。

**本节必须包含：** 术语中英对照、原理解释、可运行代码、执行链路、项目集成、测试、Summary 和 3–5 道面试题。

### S7-03：Human-in-the-loop、暂停、审核与继续

**实践任务：** 在高影响操作前暂停，等待批准或拒绝，再按审核结果继续或终止。

**本节必须包含：** 术语中英对照、原理解释、可运行代码、执行链路、项目集成、测试、Summary 和 3–5 道面试题。

## 本周验收
- 三节课的代码均能按文档运行。
