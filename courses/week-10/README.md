# 第 10 周：评测与可观测性

## 本周目标
围绕“评测与可观测性”完成 3 节课，并将成果接入持续演进的项目。

## 课程安排

### S10-01：Tracing、日志、Token、延迟和成本

**实践任务：** 记录一次任务的执行轨迹、工具调用、耗时和模型用量。

**本节必须包含：** 术语中英对照、原理解释、可运行代码、执行链路、项目集成、测试、Summary 和 3–5 道面试题。

### S10-02：评测数据集、成功率与工具调用准确率

**实践任务：** 建立固定测试问题与预期结果，计算关键指标。

**本节必须包含：** 术语中英对照、原理解释、可运行代码、执行链路、项目集成、测试、Summary 和 3–5 道面试题。

### S10-03：规则评测、LLM-as-a-Judge 与回归测试

**实践任务：** 比较规则、人工评审和模型辅助评审的适用范围，建立回归测试。

**本节必须包含：** 术语中英对照、原理解释、可运行代码、执行链路、项目集成、测试、Summary 和 3–5 道面试题。

## 本周验收
- 三节课的代码均能按文档运行。
- 至少完成一项异常场景测试。
- 更新项目 README 与学习进度。
- 能口头解释本周核心架构决策。
