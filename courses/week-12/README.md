# 第 12 周：综合项目与面试

## 本周目标
围绕“综合项目与面试”完成 3 节课，并将成果接入持续演进的项目。

## 课程安排

### S12-01：AI4S Workflow Agent 架构设计

**实践任务：** 定义任务、执行实例、Pipeline 模板、工具和产物的数据模型。

**本节必须包含：** 术语中英对照、原理解释、可运行代码、执行链路、项目集成、测试、Summary 和 3–5 道面试题。

### S12-02：整合 React Flow、LangGraph、审核、工具与结果

**实践任务：** 完成任务规划、可视化、审批、执行和结果展示的端到端流程。

**本节必须包含：** 术语中英对照、原理解释、可运行代码、执行链路、项目集成、测试、Summary 和 3–5 道面试题。

### S12-03：部署、README、架构说明、演示与面试复盘

**实践任务：** 完善项目文档、演示脚本、评测结果、架构取舍和面试问答。

**本节必须包含：** 术语中英对照、原理解释、可运行代码、执行链路、项目集成、测试、Summary 和 3–5 道面试题。

## 本周验收
- 三节课的代码均能按文档运行。
- 至少完成一项异常场景测试。
- 更新项目 README 与学习进度。
- 能口头解释本周核心架构决策。
