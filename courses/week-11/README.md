# 第 11 周：生产工程与部署

## 本周目标
围绕“生产工程与部署”完成 3 节课，并将成果接入持续演进的项目。

## 课程安排

### S11-01：Prompt Injection、最小权限和数据隔离

**实践任务：** 测试不可信输入，确保工具权限由后端强制执行。

**本节必须包含：** 术语中英对照、原理解释、可运行代码、执行链路、项目集成、测试、Summary 和 3–5 道面试题。

### S11-02：超时、重试、幂等性、并发和限流

**实践任务：** 实现请求去重、超时策略、有限重试和调用限额。

**本节必须包含：** 术语中英对照、原理解释、可运行代码、执行链路、项目集成、测试、Summary 和 3–5 道面试题。

### S11-03：Docker、认证授权、监控和配置管理

**实践任务：** 容器化服务，外置配置，并记录健康检查和必要指标。

**本节必须包含：** 术语中英对照、原理解释、可运行代码、执行链路、项目集成、测试、Summary 和 3–5 道面试题。

## 本周验收
- 三节课的代码均能按文档运行。
