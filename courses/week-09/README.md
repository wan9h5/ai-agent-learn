# 第 9 周：Multi-Agent

## 本周目标
围绕“Multi-Agent”完成 3 节课，并将成果接入持续演进的项目。

## 课程安排

### S9-01：Router、Supervisor、Subagent

**实践任务：** 实现路由或监督者模式，并说明各 Agent 的职责边界。

**本节必须包含：** 术语中英对照、原理解释、可运行代码、执行链路、项目集成、测试、Summary 和 3–5 道面试题。

### S9-02：委派、并行、结果合并与失败处理

**实践任务：** 让多个子任务独立运行，汇总结果并处理部分失败。

**本节必须包含：** 术语中英对照、原理解释、可运行代码、执行链路、项目集成、测试、Summary 和 3–5 道面试题。

### S9-03：何时采用多 Agent，以及复杂度控制

**实践任务：** 比较单 Agent、多 Agent 与确定性工作流的成本、延迟和可靠性。

**本节必须包含：** 术语中英对照、原理解释、可运行代码、执行链路、项目集成、测试、Summary 和 3–5 道面试题。

## 本周验收
- 三节课的代码均能按文档运行。
- 至少完成一项异常场景测试。
- 更新项目 README 与学习进度。
- 能口头解释本周核心架构决策。
