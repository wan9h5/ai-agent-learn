# 第 4 周：Database Agent

## 本周目标
围绕“Database Agent”完成 3 节课，并将成果接入持续演进的项目。

## 课程安排

### S4-01：数据库 Schema 与元数据读取

**实践任务：** 读取测试数据库的表、列和类型，生成可供模型使用的元数据摘要。

**本节必须包含：** 术语中英对照、原理解释、可运行代码、执行链路、项目集成、测试、Summary 和 3–5 道面试题。

### S4-02：自然语言转 SQL 与结果处理

**实践任务：** 将用户问题转换成只读查询方案，执行后把结果整理成可解释输出。

**本节必须包含：** 术语中英对照、原理解释、可运行代码、执行链路、项目集成、测试、Summary 和 3–5 道面试题。

### S4-03：只读权限、SQL 限制、超时和人工确认

**实践任务：** 实现后端权限边界、查询限制、行数上限和必要的审批流程。

**本节必须包含：** 术语中英对照、原理解释、可运行代码、执行链路、项目集成、测试、Summary 和 3–5 道面试题。

## 本周验收
- 三节课的代码均能按文档运行。
- 至少完成一项异常场景测试。
- 更新项目 README 与学习进度。
- 能口头解释本周核心架构决策。
