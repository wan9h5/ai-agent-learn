# 第 6 周：LangGraph

## 本周目标
围绕“LangGraph”完成 3 节课，并将成果接入持续演进的项目。

## 课程安排

### S6-01：State、Node、Edge

**实践任务：** 用状态、节点和边表达一个最小流程，并跟踪每一步的状态变化。

**本节必须包含：** 术语中英对照、原理解释、可运行代码、执行链路、项目集成、测试、Summary 和 3–5 道面试题。

### S6-02：条件路由、循环与终止条件

**实践任务：** 根据校验结果走不同分支，设置循环上限和终止条件。

**本节必须包含：** 术语中英对照、原理解释、可运行代码、执行链路、项目集成、测试、Summary 和 3–5 道面试题。

### S6-03：Workflow 与 Agent 的区别及混合架构

**实践任务：** 把确定性校验和模型决策放进同一个可控流程，比较两者职责。

**本节必须包含：** 术语中英对照、原理解释、可运行代码、执行链路、项目集成、测试、Summary 和 3–5 道面试题。

## 本周验收
